# Campus Notify — Praktikum 3

## File dokumentasi

- `docs/ai-prompt.md` — prompt yang digunakan.
- `docs/ai-output-awal.md` — ringkasan keluaran awal AI.

Tabel pengujian masih berstatus belum diuji. Lengkapi berdasarkan hasil pada perangkat nyata. Jangan menyertakan token FCM penuh, access token, refresh token, atau rahasia backend.
